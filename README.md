#Circuit Design using Verilog HDL
# Verilog Digital Design Projects

This repository contains my Verilog HDL implementations of fundamental digital logic and sequential circuit designs. Each design includes the Verilog source code, testbench, and simulation waveform where applicable.

## 📂 Repository Structure

### 1. Combinational Circuits — `Comb_ckt_using_DFM`

Contains basic combinational circuit designs implemented using Verilog HDL and different modeling approaches.

- Adders
  - Half Adder
  - Full Adder
- Subtractors
  - Half Subtractor
  - Full Subtractor
- Multiplexers
  - 2:1 MUX
  - 4:1 MUX
  - 8:1 MUX
- Demultiplexers
  - 1:2 DEMUX
  - 1:4 DEMUX
- Encoders
  - 4:2 Encoder
  - Priority Encoder
- Decoder
  - 2:4 Decoder

### 2. Finite State Machines — `FSM`

Contains FSM implementations using Verilog HDL.

- 1010 Sequence Detector — Mealy FSM
- 1010 Sequence Detector — Moore FSM

### 3. Synchronous Counters — `Sync_counters`

Contains various counter and frequency-divider designs.

- Mod-3 Counter
- Mod-4 Counter
- Mod-5 Counter
- Mod-8 Counter
- Multiple Up/Down Counters
- Frequency Divider Circuits
  - Divide-by-1.5
  - Divide-by-2
  - Divide-by-3
  - Divide-by-4
  - Divide-by-5
  - Divide-by-8
  - Divide-by-9

### 4. Sequential Circuits — `seq_ckt`

Contains implementations of basic sequential digital circuits.

#### Latches
- SR Latch
- D Latch
- JK Latch
- T Latch

#### Flip-Flops
- SR Flip-Flop
- D Flip-Flop
- JK Flip-Flop
- T Flip-Flop

#### Registers
- SISO — Serial-In Serial-Out
- SIPO — Serial-In Parallel-Out
- PISO — Parallel-In Serial-Out
- PIPO — Parallel-In Parallel-Out
- Universal Shift Register

## 🧪 Verification

Each design is tested using a dedicated Verilog testbench.

The functionality of the circuits is verified through simulation by applying different input combinations and analyzing the corresponding output waveforms.
